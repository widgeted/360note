# 360note 功能规划

> 版本 0.1 · 2026-11-07
> 优先级：**P0 必须具备、默认稳定可用**；**P1 强烈建议、按场景渐进披露**；**P2 高级/企业/未来**。
> 频率：高 = 主路径常驻；中 = 选中笔记后的上下文或右侧面板；低 = 设置；极低 = 向导 + 命令面板。
> 状态：✅ 已实现并通过基础验证；🟡 部分实现/有边界；⏳ 设计完成但本版本未实现。

---

## 1. 体验原则与功能放置

### 1.1 主界面（高频）

只常驻：新建 / 快速捕获、搜索、笔记列表、当前编辑器、保存与同步状态。
侧栏默认：全部笔记、最近编辑、收藏、回收站、文件夹树、标签、设置入口。
右侧信息面板默认收起；编辑时隐藏管理操作，管理时弱化编辑控件。

### 1.2 中频：选中笔记后的上下文

分享、版本历史、单篇导出、移动、收藏/置顶、删除、复制链接、冲突快照（历史）、单篇 AI 摘要、单篇发布网页、评论。
位置：编辑器右上“…”菜单、右侧信息面板（信息/反向链接/评论/历史）。

### 1.3 低频：设置

同步策略、自动备份与保留、全库导入导出、恢复、传输/静态加密说明、2FA/登录设备/异常登录、默认编辑格式/模板/快捷键/主题、索引/OCR/AI 隐私、团队权限/成员/审计、API/Webhook/插件、工作区。

### 1.4 极低频：向导 + 命令面板

迁移、灾难恢复、全库恢复、审计导出、数据区域迁移、插件安装。
必须能通过 `⌘/Ctrl + K` 搜索到；向导每步只问一个问题，危险操作先预览。

### 1.5 频率/位置矩阵

| 功能 | 频率 | 位置 | 集成 |
|---|---|---|---|
| 新建/快速捕获 | 高 | 列表顶部 / PWA 快捷方式 | 模板、默认文件夹、AI 无 |
| 搜索 | 高 | 列表顶部 + 命令面板 | 标签/附件/OCR/最近 |
| 编辑/自动保存 | 高 | 编辑器 | 版本、草稿、冲突、离线 |
| 收藏/置顶 | 高 | 列表项 hover / 右侧信息 | 过滤、排序 |
| 文件夹/标签 | 高 | 侧栏 | 搜索、导入导出、移动 |
| 回收站 | 高 | 侧栏 | 批量恢复、永久删除 |
| 分享 | 中 | 编辑器顶栏 / 更多菜单 | 评论、密码、过期、审计 |
| 版本历史 | 中 | 右侧面板 | 快照、恢复、冲突 |
| 导出单篇 | 中 | 更多菜单 | 附件、PDF |
| 评论 | 中 | 右侧面板 / 公开页 | 通知、权限 |
| 模板 | 中 | 命令面板 / 编辑器 | 新建笔记 |
| 导入/全库导出 | 低 | 设置→数据 | 任务、预览 |
| 备份/恢复 | 低 | 设置→数据 | 自动调度、恢复前备份 |
| 2FA/登录设备/恢复密钥 | 低 | 设置→安全 | 登录、异常提醒 |
| 团队/成员/审计 | 低 | 设置→团队 | 工作区、权限 |

| 关于/隐私/条款 | 极低 | 设置→关于 / 页脚 | 法律页 |

| 模板 | 会议记录/日报/项目简报 | 命令面板/设置 | ✅ |
| 快捷键 | Mod+K/N/S/\/J、格式快捷键、斜杠菜单 | 全局/编辑器 | ✅ |
| 语音转文字 | Web Speech API，主动触发 | 更多菜单 | 🟡（浏览器支持差异） |
| 导出单篇 | Markdown/ZIP + 附件、HTML（内嵌图片）、A4 PDF（Chromium，10.5pt 正文） | 更多菜单 | ✅ |

**验收：**
- 两分钟内可完成“新建→写→自动保存→刷新仍在”。
- 断网后可编辑最近打开的笔记；联网后同步；冲突不静默覆盖。
- 图片拖入后刷新仍显示，导出自带图片。

- 开启 2FA 后登录必须验证码；备份码可用一次；
- 恢复密钥能重置密码并撤销所有会话；
- 删除空间会清理附件/备份文件；
- 分享撤销后公开页立即 404。

## 4. P2：高级 / 企业 / 未来

| 功能 | 说明 | 取舍 |
|---|---|---|
| **E2EE** | root key → items key → per-note key；XChaCha20-Poly1305；恢复密钥 | 会使服务端搜索/分享/AI/找回失效；需专门向导与备份策略。见 ADR-006 |
| **实时协作/CRDT** | Yjs/Automerge + 持久化 op log | 需要大幅改同步与权限；v1 不做 |
| **异地备份增强** | WebDAV、远端列表/直接恢复、失败重试 | S3 兼容上传已实现；增强需要更多凭据/网络处理 |
| **实例级备份/恢复** | pg_dump + 全量附件 + 实例配置 | 多租户恢复复杂；需 admin 向导 |
| **审计导出/SIEM** | CSV/JSON/Webhook | 企业合规 |
| **多区域/数据驻留** | 工作区选择区域 | 需要多实例/对象存储 |
| **插件/Webhook** | 声明式权限 + 沙箱；MCP | 供应链风险；必须最小权限 |
| **MCP Server** | 让 AI 工具访问笔记 | 需 scoped token + 明确授权 |
| **桌面/移动原生壳** | Electron/Tauri/React Native | PWA 已覆盖大部分；原生用于系统集成/离线全量 |
| **发布站点/自定义域名** | 将分享集合发布成博客/文档站 | 需域名、缓存、SEO 控制 |
| **评论提及/通知中心** | 高级协作 | P1 延伸 |
| **保存视图/看板/日历** | 在标签/过滤器上构建 | 避免变成数据库产品 |
| **公式/双向链接图谱** | Mermaid/Math/Graph | 视觉与性能成本 |
| **AI 语义搜索/RAG** | 本地/远程 embedding | 隐私与成本；默认关闭 |
| **多语言完整 UI** | ✅ 中英界面，可在设置内切换；默认仍由域名决定 | 更多语言 |

## 6. 明确不做（v0.1）

- 不做内容级脚本执行/插件运行时（安全边界）。
- 不做“全功能 Notion 数据库”。
- 不做实时协同光标/CRDT。
- 不做所有格式无损导入的承诺。
- 不做营销邮件；只做注册/找回验证码与账户安全通知。
- 不做默认 E2EE 的虚假承诺。
- 不做把 AI 放在主界面自动弹出的设计。
- 不做无限嵌套弹窗。
- 不做“把用户数据锁在专有包里”的导出。

## 7. 功能验收与指标

### 7.1 关键任务

1. 新用户注册 → 写下第一行 → 保存状态可理解（目标 < 60s）。
2. 搜索标题/正文/标签/附件 → 打开正确笔记（成功率 > 95%）。
3. 离网编辑 → 联网同步 → 冲突自动合并或写入历史冲突快照（0 静默覆盖）。
4. 单篇分享 → 密码/过期 → 撤销（100% 立即失效）。
5. 备份 → 下载 → 预览 → 合并/替换恢复（可重建，附件可打开）。
6. 全库导出 → 用另一工具打开 Markdown/附件（> 95% 保真）。
7. 2FA 开启 → 登录 → 恢复密钥重置（全流程可用）。
8. 移动端快速捕获 → 桌面端出现（< 5s 联网）。
9. 命令面板找到备份/恢复/导出/版本/2FA/API/AI/分享（100% 可搜）。
10. 危险操作二次确认；误删恢复成功（> 95%）。

### 7.2 产品指标（上线后，隐私友好）

- 首次记录耗时（首次打开 → 第一次保存）
- 搜索成功率（搜索后 60s 内打开结果 / 搜索次数）
- 核心任务完成率（新建、搜索、分享、导出、恢复）
- 误操作率与恢复成功率（删除→恢复）
- 功能发现率（低频功能首次使用来源：命令面板 vs 设置）
- “找不到功能/不理解状态”的反馈占比
- 新用户 7/30 天留存
- 高级功能启用率（2FA、模板、导入导出、AI）

不接入第三方行为分析；可通过自托管聚合指标/日志实现。

### 7.3 发布门槛

- P0 全部 ✅ 或明确降级说明；
- 安全清单通过（HTTPS、Cookie、CSRF、限流、上传、权限、恢复）；
- 备份恢复演练通过；
- 移动端/桌面端核心流程 E2E 通过；
- 设计验收清单通过；
- 文档（设计/记忆/质量/功能/架构/运维）更新；
- 数据迁移/回滚方案明确。
