# 360note 功能构想

基于现有能力（Markdown/富文本、文件夹/标签、版本、评论、分享、OCR、AI、备份、对象存储、团队、API）整理。按“日常收益 / 风险 / 是否依赖新基础设施”排序。

## 第一优先：低风险、直接提升日常效率

### 1. 智能视图与保存筛选

- 侧栏保存“筛选组合”：文件夹 + 标签 + 关键词 + 是否有附件 + 是否未解决评论 + 更新时间。
- 例如“本周待整理”“带 PDF 的资料”“有访客评论的分享页”。
- 复用现有列表查询，不需要新表；只新增 `saved_views` 和少量 UI。

### 2. 笔记列表批量操作

- 现有多选主要用于删除；补充批量移动文件夹、批量加/移除标签、批量导出、批量创建分享。
- 移动端多选后显示底部操作条，避免挤在顶部。

### 3. 评论中心与审核

- 跨笔记聚合评论，筛选“未解决 / 访客 / 我的笔记”。
- 支持笔记作者批量删除匿名访客评论（单条删除已实现）。
- 增加评论通知汇总，避免逐篇查看。

### 4. 分享链接管理增强

- 批量撤销、复制、二维码、生成短链。
- 自定义 slug（如 `/s/product-guide`），保留随机 token 作为兜底。
- 分享访问统计：按天、来源、设备类型；只统计聚合数据，不记录读者身份。
- 分享快照：发布时固定内容版本，后续编辑不影响已发布页面。

### 5. 搜索增强

- 搜索筛选栏：标题/正文/标签/附件名/OCR 文本/日期范围。
- 搜索关键词高亮、最近搜索、搜索历史可清除。
- 附件类型筛选（图片、PDF、Office、文本）。
- 中文分词与同义词可后续接入，不阻塞当前搜索。

## 第二优先：写作与内容能力

### 6. 图片与附件编辑

- 图片裁剪、旋转、压缩、替换、设置 alt 和说明文字。
- PDF/Office 在线预览；附件按类型分组。
- 粘贴图片时自动压缩并保留原图选项。

### 7. 版本对比与命名版本

- 两个版本并排 diff；按标题/正文/附件变化高亮。
- 手动命名版本（如“发布前”“客户确认版”）。
- 版本按天归档，避免 60 个版本被自动保存占满。

### 8. 自定义模板

- 现有会议/日报/项目模板可扩展为工作区模板。
- 支持变量：日期、作者、空间名、文件夹、标签。
- 模板可分享给团队成员。

### 9. 导入导出增强

- Obsidian vault 双向导入/导出，保留 wiki link、附件和 frontmatter。
- Notion 数据库导出子页面、Evernote 附件和 OCR 文本。
- Git/WebDAV 定时导出，适合技术用户自建备份。

### 10. 网页剪藏与外部收集

- 浏览器扩展：选中文本、整页、图片、链接一键保存。
- 邮件收件箱：转发邮件到专属地址生成笔记。
- Telegram/微信收藏机器人（需评估平台合规与隐私）。
- RSS/稍后读列表导入。

## 第三优先：AI 与知识检索

### 11. 问我的笔记（RAG）

- 只检索当前用户有权限的空间；答案附引用笔记与片段。
- 支持“总结这个文件夹”“找出相关旧笔记”“生成周报”。
- 严格开关、按空间授权、不用于训练；管理员不能读取正文。

### 12. AI 自动整理

- 自动标签建议、标题优化、摘要、相关笔记推荐。
- OCR 文本纠错、表格转 Markdown、图片描述。
- 所有 AI 操作默认手动触发，结果可撤销。

### 13. 语义搜索与相似笔记

- 在关键词搜索之外提供“意思相近”结果。
- 需要嵌入模型与索引；建议作为可选实例能力，默认关闭。

## 第四优先：协作与团队

### 14. 细粒度角色与访客

- 角色：所有者、管理员、编辑者、评论者、只读访客。
- 工作区邀请链接、成员分组、按文件夹授权。
- 成员配额：每人可创建空间数、附件上限。

### 15. 审计与合规

- 审计日志筛选（用户、动作、时间、IP）、CSV/JSON 导出。
- 分享访问聚合报表导出。
- 管理员操作二次确认与不可否认日志。

### 16. 通知与订阅

- 评论、@提及、分享访问、备份失败、存储失败通知。
- 邮件摘要频率可调；重要安全事件实时提醒。
- Webhook / 企业微信 / Slack 通知。

## 第五优先：备份、运维与安全

### 17. 备份增强

- 对象存储内浏览、校验、直接恢复（目前需下载后上传）。
- 增量备份与去重，降低整站备份体积。
- 定期自动恢复演练，输出完整性报告。
- 用户级自有对象存储备份（区别于站点级附件存储）。

### 18. 安全增强

- Passkeys / WebAuthn 登录。
- 登录设备管理与风险提醒（新地区、新设备、频繁失败）。
- 2FA 恢复码下载、管理员强制 2FA。
- API token 细粒度权限、过期时间、使用记录。

### 19. 监控与告警

- 备份失败、对象存储不可用、SMTP 失败、任务堆积、磁盘不足告警。
- 管理概览增加 7 天趋势：笔记、附件、分享、失败任务。
- 健康检查端点区分数据库、存储、邮件、OCR、AI。

## 体验与可访问性

### 20. 移动端手势与导航

- 笔记列表左滑收藏/置顶，右滑删除/移动。
- 编辑器手势返回、底部快捷导航。
- 离线状态更明确，冲突合并可视化。

### 21. 可访问性与个性化

- 完整键盘导航、焦点环、屏幕阅读器标签。
- 快捷键自定义。
- 字体、行宽、段落间距、打印主题。

## 建议的下一轮顺序

1. 智能视图 + 批量操作（高频、低风险）。
2. 评论中心 + 分享统计/快照（现有能力自然延伸）。
3. AI 摘要/自动标签/问笔记（先做权限与引用，避免黑盒）。
4. 备份远端浏览/直接恢复 + 用户级对象存储。
5. Passkeys、通知与监控告警。

## 暂不建议优先做

- 实时多人协同（CRDT）成本高，当前版本冲突处理已够用。
- 附件直接暴露对象存储 URL：会破坏现有登录鉴权与加密边界；如追求 CDN，需要单独设计短期签名或端到端加密方案。
- 管理员读取笔记正文的“支持模式”：与当前隐私边界冲突，不建议加入。
