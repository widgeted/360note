# 缤纷云 CoreIX 功能规划

> 版本：2026-11-11 · 以“解决真实问题”为准，不以功能数量为目标。
> 原则：只有当功能能减少失败、减少等待、减少流量、提升搜索命中或降低误操作时才做；不能改变用户原图、不能绕过分享权限、不能增加长期维护负担。

> 说明：下表中的 CoreIX 能力已在代码中实现，但生产环境只有在配置媒体访问域名且附件对象存储启用后才真正执行；未配置时按第 4 节回退。

## 1. 已落地：解决的具体问题

| 用户问题 | 已做能力 | 用户体验/性能收益 |
|---|---|---|
| 分享页图片太大、加载慢 | `fmt=auto/webp/jpg`、`q`、`w` | 分享图片体积下降，弱网和移动网络更快；原图仍可下载 |
| 公开分享图片需要权限保护 | 服务端代理 CoreIX | 分享密码、过期、撤销继续生效，浏览器不直接接触媒体对象 |
| 截图、发票、文档里的文字搜不到 | `fmt=aesthetics` 的 `utility` + `fmt=tags` + OCR | 搜索“截图/发票/文档”或图片内文字可找到笔记 |
| 用户不知道图片场景/内容 | `fmt=tags` | 附件区显示图片标签，便于整理；可选择自动加入笔记标签 |
| 存储配置容易误触 | 备份/附件连接设置默认折叠 | 降低误改 Endpoint/Bucket/密钥导致附件失联的风险 |
| 对象表格换行、行高失控 | 单行、横向滚动、筛选、CSV | 管理长列表可读、可扫读、可导出，不靠换行撑高度 |
| 不知道媒体域名填什么 | 明确为 CDN 媒体域名根 | 避免填成 S3 Endpoint 或 `<bucket>.<endpoint>` |

## 2. 下一阶段：只做高价值项

### P1.1 输入兼容：HEIC / HEIF / RAW / PDF / SVG（已落地）

**问题**：当前上传拒绝 HEIC/HEIF，iPhone 用户必须先转换；PDF/SVG 只显示文件图标。

**做**：允许上传后由 CoreIX 生成 WebP/JPEG 预览；PDF 取第一页，SVG 转安全位图；原文件仍加密保存。

**收益**：减少上传失败和手动转换；PDF/图片在列表和分享页可直接识别。

**成本/风险**：需要处理超大图、转换失败回退、原文件下载。**已实现：CoreIX 生成 WebP 缩略图，原文件加密保留。**

### P1.2 PDF / 视频封面（已落地）

**问题**：PDF、视频在笔记里只有文件图标，无法快速判断内容。

**做**：PDF 用 `frame=0/auto`，视频/动图用 `frame=auto` 生成封面。

**收益**：列表、附件区和分享页更易辨认；减少打开文件确认的次数。

**成本/风险**：转码耗时、失败回退。**已实现：PDF frame=0，视频 frame=auto，生成加密缩略图。**

### P1.3 ThumbHash / 主色占位

**问题**：图片加载前是白块，弱网时布局跳动。

**做**：保存 `fmt=thumbhash` 或 `fmt=blurhash` 与 `fmt=palette`，加载前显示占位。

**收益**：降低 CLS、减少白屏感；对分享页和长列表有效。

**成本/风险**：需要缓存和回退；只在图片附件上做。**值得做，排第二。**

### P1.4 CoreIX OCR 评估

**问题**：本地 tesseract 对中文、截图、发票的识别质量不稳定。

**做**：在相同图片集上对比 CoreIX OCR 与本地 OCR；只有准确率明显更高且成本可控时才切换，保留本地降级。

**收益**：搜索命中率提升；减少错误文字。

**成本/风险**：外部请求、费用、隐私。**先评估，不直接替换。**

## 3. 有条件再做

| 能力 | 适用条件 | 不做的理由 |
|---|---|---|
| `fmt=phash` 重复图片检测 | 用户确实有大量重复上传 | 更像存储清理工具，不是核心写作流程；先做统计再决定 |
| `fmt=tpng` 截图压缩 | 截图附件占比高且带宽压力明显 | `fmt=auto` 已覆盖大部分收益，单独开关增加维护 |
| `pos=auto` 智能裁切 | 列表缩略图需要主体保留 | 现有 object-fit 已可接受；需大量视觉回归 |
| `face-blur` 人脸打码 | 用户明确需要公开分享隐私保护 | 误识别风险；必须默认关闭、逐张确认 |
| `enhance`/HDR/水印 | 用户主动选择 | 自动修改原图观感会破坏“内容属于用户”的信任；默认不做 |

## 4. 配置前提与回滚

- 媒体访问域名必须已完成 ICP 备案；已备案主域的子域名通常无需单独备案，但以 CDN 服务商审核为准。未备案域名无法添加为缤纷云 CDN 加速域名。
- 配置顺序：完成备案 → 在缤纷云 CDN 添加媒体域名并绑定附件桶 → 配置 CNAME 与证书并等待生效 → 在 360note 填入域名根地址 → 保存并测试。
- 媒体域名不是 S3 Endpoint，也不是 `<bucket>.<endpoint>`；只填域名根，例如 `https://img.example.com`。
- 媒体副本不加密，必须使用私有桶、CDN 高级鉴权或等效访问控制；建议配置 CDN 鉴权 Key，让服务端生成带时效的 `_btf_tk/_ts` 签名 URL。
- `mediaBaseUrl` 未配置、域名未生效或 CoreIX 处理失败时自动回退：分享图片返回原图，图片标签不生成，功能性图片识别回退本地 OCR，HEIC/PDF/视频封面回退文件图标或链接，不阻塞上传与分享。
- 未分享的笔记图片不生成永久媒体副本；功能性图片分析使用临时对象，分析后立即删除。

## 5. 明确不做

- 不做视频剪辑、视频转 GIF、动图编辑：偏离笔记产品。
- 不做自动美化/自动 HDR/自动水印：用户没有要求，且会改变原图。
- 不做美学评分排序：没有真实的封面/图库流程支撑。
- 不做 `featureprint` 相似图搜索：当前搜索已覆盖标题、正文、标签、OCR，收益不足。
- 不做默认人脸打码：误伤和隐私判断复杂，先保留可选能力。

## 6. 衡量指标

- 上传失败率（尤其 HEIC/RAW/PDF）
- 分享图片平均传输字节数
- 分享页 LCP / CLS（图片占位上线后）
- OCR 搜索命中率与误识别率
- 图片标签搜索点击率
- 对象存储管理页误操作/回滚次数
- 媒体处理失败率与回退原图比例

## 7. 验收清单

- [ ] HEIC/RAW/PDF/SVG 上传后可预览，原文件仍可下载。
- [ ] PDF/视频封面失败时回退文件图标，不阻塞上传。
- [ ] 图片占位不改变正文布局，弱网无白块跳动。
- [ ] CoreIX OCR 评估有数据结论，未达标不切换。
- [ ] 所有媒体处理失败都能回退原图。
- [ ] 分享密码、撤销、过期在媒体代理下仍生效。
- [ ] 未分享图片不产生永久媒体副本。
