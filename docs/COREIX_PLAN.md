# 缤纷云 CoreIX 功能规划

> 版本：2026-11-11 · 基于 CoreIX V4.0 更新记录与 360note 现状。
> 原则：先解决可搜索、可访问、可恢复的基础能力，再做视觉增强；所有媒体处理必须经过分享权限代理，不能绕过密码/撤销/过期。

## 1. 已落地（P0）

| 能力 | CoreIX 参数 | 项目落地 |
|---|---|---|
| 分享图片格式优化 | `fmt=auto/webp/jpg` | 服务端代理公开/密码分享图片；原附件仍 AES-256-GCM 加密 |
| 质量与宽度控制 | `q=40–95`、`w` | 管理端可配置，默认 82 / 1600px |
| 场景/物体标签 | `fmt=tags` | 分享时异步分析，存 `attachments.image_tags`，编辑器附件区展示 |
| 功能性图片判断 | `fmt=aesthetics` → `utility` | 上传图片临时分析；截图/发票/文档自动排队 OCR，临时媒体对象立即删除 |
| OCR 文本搜索 | 本地 tesseract + `ocr_text` | 截图/发票/文档图片中的文字可搜索 |
| 图片标签搜索 | `image_tags::text` | 搜索“截图”“发票”“document”等可命中相关笔记 |
| 媒体域名与 CDN 鉴权 | `_btf_tk` / `_ts` | 服务端生成签名 URL；浏览器始终走站点代理 |
| 附件/备份存储拆分 | — | `attachmentStorage` 与 `offsite` 独立；旧配置自动回退 |

## 2. 下一阶段（P1，优先开发）

### 2.1 HEIC/HEIF、RAW、PDF、SVG 输入兼容

- 现状：上传入口拒绝 HEIC/HEIF/TIFF/BMP；SVG 不进入图片处理。
- 目标：允许上传后由 CoreIX 转成 WebP/JPEG 预览；原文件仍加密保存。
- 参数：`fmt=webp|jpg`、`w`、`q`；PDF 使用 `frame=0` 取第一页；SVG 使用 `fmt=png` 或 `fmt=keep` 清理危险内容。
- 价值：iPhone/相机用户可直接上传，不要求手动转换。

### 2.2 PDF 与视频封面

- PDF 使用 `frame=0`（或 `frame=auto`）生成封面/缩略图。
- 视频/动图使用 `frame=auto` 选择清晰美观的一帧作为附件缩略图。
- 价值：PDF、视频不再只有文件图标；分享页和列表更易识别。

### 2.3 占位与主色

- `fmt=thumbhash` 或 `fmt=blurhash` 存到附件元数据，编辑器/分享页图片加载前显示轻量占位。
- `fmt=palette` / `fmt=color` 提取主色，用于图片骨架背景和分享页主题。
- 价值：弱网和大陆访问 CDN 时显著减少布局跳动和“白块”。

### 2.4 重复图片检测

- `fmt=phash` 存 64 位感知哈希；汉明距离 ≤10 视为同一图。
- 上传时提示“可能重复”，允许复用已有附件；后续可做清理工具。
- 价值：节省存储、减少重复附件和备份体积。

### 2.5 截图/图标量化压缩

- 对 PNG 截图/线稿使用 `fmt=tpng` 或 `fmt=webp` 无损调色板编码。
- 价值：截图类附件体积明显下降，文字仍清晰。

## 3. 后续阶段（P2）

- **智能裁切**：`pos=auto` 保留人脸/主体，用于列表缩略图。
- **人脸隐私**：`face-blur` 或 `face-pixel`，分享前可选“自动模糊人脸”。
- **自动增强/调色**：`enhance`、`bri`、`con`、`sat`，只作为用户可选，不默认改变原图。
- **HDR 控制**：`hdr-rate` 限制刺眼亮度；分享页默认保留 HDR，提供 SDR 开关。
- **水印**：文字/图片/SVG 变量水印，用于公开分享防搬运；默认关闭。
- **美学评分**：`fmt=aesthetics` 的 `overall` 用于封面/图库选择。
- **CoreIX OCR**：官方 OCR 接口支持多语言；待账号开通后用于替代本地 tesseract，保留本地降级。
- **相似图搜索**：`fmt=featureprint` 768 维向量，用于“找相似图片”。

## 4. 约束与回滚

- 所有媒体处理只针对**可分享笔记的图片**；未分享图片不做永久媒体副本。
- 功能性图片检测使用临时对象，分析后立即删除；失败时回退本地 OCR。
- `mediaBaseUrl` 未配置或 CDN 不可用时自动回退原图，不影响附件访问。
- 原附件始终加密；媒体副本是独立未加密对象，必须使用私有 CDN/鉴权或专用媒体桶。
- 新增参数先在临时数据库 + 本地 S3/CoreIX 测试环境验证，不在生产直接试错。

## 5. 验收清单

- [ ] HEIC/RAW/PDF/SVG 上传后可生成预览，原文件仍可下载。
- [ ] `fmt=thumbhash`/`palette` 有缓存与降级。
- [ ] 重复图片提示不阻塞正常上传。
- [ ] 分享密码、撤销、过期在媒体代理下仍生效。
- [ ] 功能性图片检测失败时 OCR 仍可用或给出明确状态。
- [ ] 搜索“截图”“发票”和 OCR 文本均能命中。
- [ ] 临时分析对象无残留、无公开 URL 泄漏。
