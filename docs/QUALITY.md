# 360note 质量规范

> 版本 0.1 · 2026-11-07  
> 质量不是“测试通过”，而是：用户敢把内容交给你；出错时能发现、能恢复、能解释。

---

## 1. 质量目标

### 1.1 可靠性

- **不丢数据**是最高优先级。任何保存/删除/恢复路径都必须在失败时保留可恢复副本。
- 自动保存失败必须可见；离线必须进入本地 outbox；冲突绝不静默覆盖。
- 单条笔记版本、回收站、备份、导入预览、恢复前备份构成多层恢复网。
- 服务端/客户端崩溃后，重启可恢复；数据库迁移幂等；任务可重试/有明确失败状态。

### 1.2 安全

- 默认安全：无默认密码、无默认 admin、无默认 secret；生产缺少密钥直接启动失败。
- 最小权限：每个 API 请求检查工作区成员关系与角色；列表不依赖 UI 过滤。
- 所有状态变更防 CSRF；会话 HttpOnly/Secure/SameSite；登录与敏感操作限流。
- 上传内容不信任 MIME/文件名；路径不可穿越；公开附件设置 CSP；分享 token 高熵且哈希存储。
- 账户邮件 = 验证码限流、尝试次数限制、邮箱枚举防护；恢复密钥仍是重要的离线找回方式。

### 1.3 性能

目标（单工作区 1 万篇、附件 1GB、普通 4 vCPU/8GB 服务器）：

| 操作 | 目标 | 备注 |
|---|---|---|
| 首屏可交互 | < 1.0s（缓存命中） | 列表摘要 + 应用 shell |
| 打开笔记 | < 300ms（缓存/本地 DB） | 不含大附件下载 |
| 搜索 | < 300ms p95 | 1 万笔记，含标签 |
| 自动保存 ack | < 500ms p95（同区域） | 用户感知“已保存” |
| 保存失败可见 | < 3s | 网络错误/5xx |
| 附件上传 5MB | < 3s（10Mbps） | 不含 OCR |
| 备份 1GB | < 10min | 服务器本地 |
| PDF 导出 | < 15s/篇 | Chromium |
| 导入 500 篇 | < 5min | 同步任务 + 进度 |

超过目标必须记录在 `MEMORY.md`，并在发布说明中注明。

### 1.4 可用性

- 核心流程不依赖鼠标；键盘可完成新建/搜索/打开/保存/关闭弹窗。
- 移动端 390px 无横向溢出；触控目标 ≥ 40px；底部安全区适配。
- 全站中英文混排可读；日期/数字本地化；不出现“undefined/NaN”。
- 状态有文字/图标，不只靠颜色；错误信息给出下一步。
- 空状态有行动；加载状态不闪烁；骨架/Spinner 二选一，不叠加。

### 1.5 可维护性

- 共享类型在 `packages/shared`；前后端不复制接口类型。
- 设计 token 集中；不写魔法颜色/间距。
- 重要决策写 ADR；修改历史写 CHANGELOG/MEMORY。
- 迁移只增不改；破坏性变更必须提供回滚/导出路径。
- 依赖更新前读 CHANGELOG；锁定版本；生产只装 dependencies。

### 2.3 E2E 最低通过集（发布门槛）

- 登录 → 新建 → 输入 → 保存 → 刷新仍存在。

- 分享只读页无登录打开；撤销后 404。
- 回收站删除→恢复。
- 备份→下载→上传→预览→合并恢复；替换恢复由 pre-restore 可回退。
- 导入 ZIP → 预览 → 执行 → 笔记/附件出现。
- 2FA 开启 → 登录 → 关闭/恢复密钥。
- 移动端新建→桌面可见（或同步状态明确）。
- 设置每个页面加载无 JS 错误。

## 3. 安全清单（发布前必须逐项确认）

### 3.1 传输/部署

- [ ] HTTPS 全站；HTTP 301 到 HTTPS；HSTS 开启（含子域）。
- [ ] TLS 证书有效期与自动续期。
- [ ] Nginx 不暴露目录列表；`server_tokens off`。
- [ ] 仅 80/443/SSH 对外；Postgres/Redis 只监听 127.0.0.1。
- [ ] systemd 服务以非 root 用户运行；数据目录 0700；env 0600。
- [ ] 备份/附件目录不可通过 Nginx 直接访问。

### 3.2 应用

- [ ] 生产 env：`SESSION_SECRET` 随机 ≥32 字节；`NOTE360_MASTER_KEY` 32 字节 base64；无默认值。
- [ ] 注册模式/邀请码符合预期；首个用户 admin 已知。
- [ ] Cookie：`__Host-`、Secure、HttpOnly、SameSite=Lax、Path=/。
- [ ] CSRF：所有非 GET 请求自定义头；Bearer 豁免；Origin/SameSite 检查。
- [ ] 登录/注册/分享解锁/AI 限流；账户锁定。
- [ ] 密码 scrypt 参数；计时安全比较；密码不写日志。
- [ ] 2FA secret 加密存储；备用码哈希；`totp_last_step` 防重放。
- [ ] 恢复密钥只存哈希；重置撤销全部会话并关闭 2FA。
- [ ] 会话撤销即时生效；设备/IP 记录可解释。
- [ ] 分享 token 哈希 + 高熵；密码 scrypt；过期/撤销；无 token 出现在日志/Referer（分享路径除外，需 `Referrer-Policy`）。
- [ ] 上传：大小限制、MIME 嗅探、文件名安全、路径穿越防护、CSP、`X-Content-Type-Options`。
- [ ] SQL 全部参数化；无字符串拼接。
- [ ] XSS：服务端 HTML `sanitize-html`；客户端 DOMPurify；CSP；SVG/HTML 附件 CSP。
- [ ] 越权：所有 note/folder/tag/attachment/share/backup API 检查工作区/角色；列表查询带成员条件。
- [ ] 审计：登录、2FA、密码、恢复密钥、分享、备份、团队、导出、删除。
- [ ] 错误响应不泄露 SQL/堆栈/内部路径。
- [ ] 备份文件加密；下载仅管理员；恢复先预览 + 安全备份。
- [ ] AI key 加密；默认关闭；用户主动触发；加密笔记拒绝。

### 3.3 依赖与运维

- [ ] `npm audit` 无 high/critical（或有记录豁免）。
- [ ] 依赖锁定；生产只装 dependencies；构建产物不含 source map（可选）。
- [ ] 日志不含密码/token/Cookie/正文。
- [ ] 备份/恢复演练完成并记录。
- [ ] 管理员账户密码足够强，恢复密钥离线保存。
- [ ] 隐私政策/条款与实际行为一致（仅账户邮件、无训练、E2EE 未提供）。
- [ ] 数据删除路径验证（注销/删除空间/附件/备份清理）。
- [ ] 事件响应联系人/步骤（应用内公告 + 必要的账户安全邮件）。

## 4. 数据完整性规则

1. 所有内容有稳定 UUID。
2. 标题与正文分离；重复 H1 在服务端/客户端剥离。
3. 笔记保存必须带 `baseVersion`（编辑器路径）；服务端冲突返回 409 + 当前版本。
4. 删除笔记 = 回收站；永久删除清理版本/分享/评论/附件；文件夹删除递归标记笔记回收站。
5. 版本快照最多 60；恢复产生新版本，不覆盖历史。
6. 附件必须先写文件成功再写 DB；删除先删 DB 再删文件，失败可清理孤儿；所有路径校验。
7. 导入创建新笔记，不覆盖现有内容；预览与执行分两步。
8. 备份包含 manifest/workspace.json/attachments；恢复替换前必须创建安全备份。
9. 分享撤销/过期立即生效；编辑分享不得把公开 URL 写回正文。
10. 审计记录不得阻塞主操作；失败仅记录日志。

## 5. 可访问性与设计验收

- [ ] 语义化 `button`/`a`/`input`；图标按钮有 aria-label。
- [ ] 模态框 focus trap、Esc、焦点回退。
- [ ] 表单 label 与输入关联；错误 `role=alert`。
- [ ] 颜色对比；深色模式检查；选中/悬停/hover/focus 状态。
- [ ] **全站无衬线/宋体**：源码搜索 `serif`、`Songti`、`Newsreader` 为零；浏览器计算字体为 Inter/系统无衬线。
- [ ] **所有界面文字 ≥ 13px**：包含隐私政策、服务条款、忘记密码、快捷键、时间戳、错误说明。
- [ ] **hover/active 只改颜色**：无下划线、无 translate/scale、无阴影跳变。
- [ ] **按钮同一层级一致**：高度 30/36/44px、圆角 7/8px、1px 边框、统一内边距与字号。
- [ ] **边框不重叠**：相邻元素无双线；选中态不再叠加 ring 或第二层 box-shadow；设置导航使用透明占位边框避免 1px 位移。
- [ ] **主题一致**：浅色主题侧栏为暖纸色，深色主题侧栏为深色；切换后无需刷新即生效。
- [ ] **折叠侧栏**：56px 内新 mark、通知、展开按钮不重叠，展开按钮图标正确切换。
- [ ] **内联命名**：新建/重命名文件夹与标签不弹窗，输入框位于列表/原名位置，Enter 保存、Esc 取消。
- [ ] **通知深链**：评论通知定位到目标评论，共享编辑通知打开对应版本；通知行有明确动作词。
- [ ] **图标唯一**：新便签 mark 同时用于侧栏/认证页/favicon/PWA/apple-touch；同一场景不混用两套设备/浏览器图标；favicon 缓存版本已更新。
- [ ] **深色底图标可见**：所有深色背景按钮/徽章/勾选态使用显式对比色，不出现“黑点”。
- [ ] **浮层滚动**：通知中心、菜单、下拉列表内部滚轮/滚动条拖动时保持打开，只有外部点击/Esc 关闭。
- [ ] **标签云**：侧栏标签使用 # 图标、可一行多个、标签区与设置分隔线间距 ≥24px。
- [ ] **控件档位**：设置页输入/下拉统一 36px（紧凑 30px），没有随手高度。
- [ ] **网格等高**：导出、导入预览、恢复预览、统计等卡片行高一致，无 sibling margin 漏入 Grid。
- [ ] **菜单统一**：普通菜单内容自适应（`max-content`，140–360px）；图标“…”右对齐、全宽触发器左对齐；空间切换菜单与触发器等宽；不得贴 0px 边缘；退出登录菜单只容纳最长选项。
- [ ] **移动端浮层**：空间切换菜单浮在侧栏之上，可点击切换；移动端侧栏无阴影；菜单图标在搜索框左侧且与设置图标不同。
- [ ] **通知蓝点**：所有通知已读后立即消失；旧评论/共享编辑通知仍能打开目标面板。
- [ ] **头像热区**：折叠侧栏头像按钮边界与头像一致，不包含上下空白。
- [ ] **空间入口**：管理空间与创建空间进入不同状态；创建成功后才关闭创建弹窗。
- [ ] **编辑器模式**：Markdown 模式没有顶部提示条和第二个 footer；模式在切换笔记后保持；聚焦只通过底栏退出。
- [ ] **打印**：分享页打印隐藏评论/目录/按钮，发布与打印时间为 `yyyy年MM月dd日 HH:mm`，更新时间为相对时间。
- [ ] **表格**：进入表格后可直接加/删行、列和删除整表，无需先选中表格。
- [ ] **附件删除**：信息面板附件删除后立即消失；列表只显示仍被正文引用的附件。
- [ ] **单一状态**：保存状态只出现在编辑器右上角，字数只在标题元信息，字符数只在底栏。
- [ ] **注册排版**：桌面端 560px 卡片、2×2 字段网格、表单字段间距 ≥17px；移动端单列；字段标签与输入框不粘连。
- [ ] **分享排版**：作者/时间与操作分组；评论表单卡片化；附件列表带图标；页脚不重复品牌全称。
- [ ] **Wiki 链接**：编辑器中只显示标题（括号视觉隐藏），普通单击跳转；目标不在当前过滤结果时仍可搜索解析。

## 7. 备份与恢复演练规范

**频率**：每次发布前、每月一次。

**步骤**：
1. 在一个测试工作区准备：嵌套文件夹、标签、2 张图片附件、1 个 PDF、10 个版本、3 条评论、中英文标题。

**通过标准**：0 数据丢失、附件全部可打开、版本可恢复、pre-restore 可用。

## 9. 事故响应（简化 Runbook）

1. **确认影响**：登录/数据/分享/附件/备份。
2. **止血**：回滚最近部署；关闭注册/分享/AI（如相关）；必要时只读维护页。
3. **保护证据**：保存日志、审计、数据库快照；不要覆盖。
4. **恢复**：从最近备份/时间点恢复；先恢复预览；优先恢复数据而非追求快速上线。
5. **通知**：应用内公告/状态说明；说明影响、已做措施、用户需做什么。
6. **复盘**：根因、时间线、影响、修复、预防；写入 `MEMORY.md` 与 `CHANGELOG.md`。
7. **验证**：恢复后执行备份演练核心集。

账户邮件：仅验证码、安全通知与邀请；日常评论/登录提醒仍在应用内。文档需说明这一边界。

## 10. 已知风险与缓解

| 风险 | 影响 | 缓解 |
|---|---|---|
| 无 E2EE | 服务端可读正文 | 明确披露；TLS、最小权限、审计、可导出；未来 E2EE 计划 |
| 离线缓存不全 | 较早笔记离线打不开 | 打开即缓存 + 后台预取最近 120 篇；UI 标注 |
| 附件离线不可上传 | 离线写作受限 | 明确提示；计划队列 |
| 分享编辑匿名 | 滥用/误改 | 默认仅查看；可编辑需主动选择；版本保留；审计/通知 |
| 备份默认同机 | 服务器灾难丢失 | 可下载；管理员可配置 S3 兼容异地备份 |
| 中文搜索 | 分词不足，大库慢 | trigram + ILIKE；基准；未来分词/搜索服务 |
| 导入保真 | 复杂格式丢失样式 | 预览/警告；标准 Markdown 导出兜底 |
| 邮件服务故障 | 新用户无法注册、无法邮件找回 | 恢复密钥；管理员协助；监控 SMTP |
| 依赖/浏览器 | 语音/PDF 依赖环境 | 功能降级与明确错误；PDF 可 HTML 打印 |
| 任务无重试 UI | 导入/备份失败需重试 | 任务状态/错误；用户可重新执行；计划重试按钮 |

## 11. 编码与评审约定

- TypeScript strict；不用 `any` 除非边界并有注释。
- API 输入必须 zod 校验；输出类型来自 shared 或显式映射。
- SQL 参数化；事务包裹多步写；错误用 AppError。
- 前端 fetch 统一走 `lib/api.ts`；不手写 CSRF/凭据。
- 所有用户可见字符串走 `t()`（当前中文优先；英文未完成前不默认切换）。
- 组件不超过合理复杂度；重复逻辑提取到 hooks/lib。
- 不做未经文档化的“顺手功能”；功能必须进 FEATURES/DESIGN。
- PR/提交信息说明“为什么”，不仅是“改了什么”。
- 重要决策/踩坑当天写入 MEMORY；版本变更写 CHANGELOG。
