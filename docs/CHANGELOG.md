# Changelog

All notable changes to 360note are documented here.  
Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions use [Semantic Versioning](https://semver.org/).

## [0.1.5] — 2026-11-08

分享、表格、导出、保存并发与视觉收敛。

### Added

- 分享对话框在已有有效链接时提示“访客看到最新版本”，创建分享后 toast 说明后续编辑会同步。
- 表格上下文栏：上方/下方加行、左侧/右侧加列、删除当前行/列、删除整表。
- 信息面板附件删除（两次点击确认）。
- 空间概览与个人/团队空间说明；创建弹窗可选择个人/团队。
- 新增 demo 账号与覆盖中英文/Markdown/富文本/表格/图片/附件/标签/文件夹/评论/版本/分享/回收站/备份的演示数据；凭据不写入仓库。
- 分享页专用打印样式：A4、完整日期/打印时间、隐藏评论和界面操作。

### Changed

- PDF 导出改为 A4、10.5pt 正文、22pt 标题，接近编辑器在合适宽度下的阅读效果。
- Markdown 模式移除顶部提示条和 `.source-footer`，只保留 `.editor-footbar`。
- 聚焦模式移除右上悬浮按钮，底栏按钮切换“聚焦/退出聚焦”。
- 编辑模式持久化，切换笔记或离开后仍保留富文本/Markdown 选择。
- 普通菜单改为内容自适应（140–360px）；Dropdown 使用真实触发按钮定位；退出登录菜单只容纳最长选项。
- 新建笔记按钮改为白底细边框、蓝色图标，降低视觉重量。
- 删除侧栏“已同步”和移动端同步点，只保留编辑器右上保存状态；底部只保留字符数。
- 历史“保存版本”按钮由虚线改为实线。
- 头像改为圆形白字；品牌默认改为 `360note.` 文字标识（蓝色句点），折叠侧栏才显示 `N.`；favicon/PWA/apple-touch 同源。
- 账户页显示名称/邮箱/保存按钮同列，控件统一 36px。
- 切换板块立即清空旧列表并显示 loading skeleton，避免延迟显示不匹配内容。

### Fixed

- 自动保存并发导致同一 baseVersion 的 PATCH 竞争和大量冲突副本：保存改为单飞 + 合并排队；冲突内容改存版本历史（第六轮）。
- 上传附件/导出 PDF 时持续编辑产生冲突副本。
- 删除附件后信息面板继续显示旧附件。
- 历史保存版本虚线不符合控件规范。
- 富文本/Markdown 模式每次进入笔记被重置。
- Banner/Toast 图标与文字对齐不一致；安全页提示与技术标题间距过窄。
- 分享页打印缺少专用版式与完整时间格式；打印保留完整发布/打印时间，更新时间使用相对时间。
- 深蓝海军色 toast/代码表面改为暖炭色；附件列表只显示仍被正文引用的附件。
- 移除移动端底部的重复新建按钮，顶部新建按钮与桌面端统一样式；移动栏只保留笔记/搜索/收藏/设置。
- 头像改为单字母圆形标记；分享页增加复制链接；空间命名弹窗焦点稳定。
- 空间创建弹窗可选择“个人空间/团队空间”；个人空间可创建多个，删除时至少保留一个空间。
- 修复 Modal 焦点 effect 依赖每次渲染变化的 `onClose`，避免空间命名/分享/上传弹窗每个字符失去焦点或闪烁。
- 用户菜单移除重复的账户/外观/安全入口，只保留退出登录。
- 移动端底部新建按钮最终移除，新建仅保留顶部与桌面同款按钮；快速栏四等分。（第七轮整体移除底部快速栏。）
- 清理测试登录通知，铃铛未读蓝点与真实未读状态一致。

## [0.1.1] — 2026-11-08

入口、视觉与错误体验纠偏。此版本没有新增功能，重点是去掉营销外壳与“AI 味”，把产品本身放到第一屏。

### Changed

- **入口即产品**：`/` 直接进入 `/app`；未登录显示登录页。删除营销首页及其样式。
- **全站无衬线**：移除 Newsreader、宋体/衬线 token 与编辑器衬线偏好；登录、笔记标题、分享页、导出、错误页统一 Inter/系统无衬线。
- **字号下限 13px**：隐私政策、服务条款、忘记密码、时间戳、错误说明等全部提升；“任何文字不得小于 13px”写入设计规范与验收清单。
- **品牌改为文字标识**：`360note.`（蓝色句点），PWA/favicon 为同源 `N.`；删除旧图形 logo。
- **按钮统一**：标准 36px / 小号 30px / 大号 44px；圆角 8/7px；同一层级的边框、内边距、字体一致。
- **去掉廉价交互**：删除 hover 下划线、按钮上浮/缩放、active 位移、选中态额外 ring；hover 只改变颜色或背景。
- **边框纪律**：修复搜索/新建按钮溢出、选中态双边框、共享权限卡与设置导航的阴影描边；相邻元素保持单层 1px 边框。
- **空状态与文案**：去掉 emoji 与 Sparkles 图标，改用书写类图标；种子笔记去掉 👋；降低“AI 生成”语气。
- **错误体验**：Nginx 静态直出 SPA；502/503/504 显示 360note 品牌 503 页；前端把网关错误转为可读中文，不再渲染 Nginx HTML。

### Fixed

- 注册 502：`archiver@8` ESM 启动失败导致 API 不可用；回滚 `archiver@7.0.1` 并重新部署。
- API 重启时登录页不再整站 502：静态资源由 Nginx 提供。
- `www` 与 HTTP 重定向、HSTS/CSP 保持。

### Docs

- `docs/DESIGN_SYSTEM.md` 升级 0.2：禁止衬线、13px 下限、禁止 hover 位移/下划线、按钮分级、边框规则、直接登录、错误页、反模式与验收清单。
- `docs/MEMORY.md` 记录视觉纠偏与“每次更新立即推送 GitHub”铁律。

## [0.1.0] — 2026-11-07

首个可部署版本。目标：把“稳定记录、找得回来、多端可用、安全透明、可携带、可恢复”做扎实。

### Added

**应用与编辑**

- React PWA：三栏桌面布局、移动单屏、可安装、暗色模式、命令面板。
- TipTap 富文本编辑器 + Markdown 源码模式；标题/列表/表格/任务/引用/代码块/图片/附件/链接/双向链接。
- 自动保存（800ms）、草稿恢复、撤销、版本历史（最多 60 个快照）、回收站。
- 模板：会议记录、日报、项目简报；斜杠菜单；格式快捷键；语音输入（Web Speech API）。
- 图片拖动/粘贴上传；附件 AES-256-GCM 加密存储；OCR 可选（tesseract + pdftotext）。
- 网页剪藏 bookmarklet、PWA 快捷方式 `/new`、`/search`、Web Share Target `/clip`。

**组织与搜索**

- 文件夹树、标签、收藏、置顶、最近编辑、回收站。
- 全文搜索：标题/正文/标签/附件名/OCR；FTS + trigram + ILIKE；结果片段。
- 双向链接与反向链接；文件夹/标签过滤；排序（更新/创建/标题/打开）。
- 批量选择、批量删除/恢复/永久删除。

**同步与离线**

- IndexedDB 工作区/笔记缓存、草稿、outbox。
- 服务端版本号乐观并发；409 时行级三向合并（node-diff3）。
