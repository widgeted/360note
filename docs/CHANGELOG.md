# Changelog

All notable changes to 360note are documented here.  
Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions use [Semantic Versioning](https://semver.org/).

## [0.1.15] — 2026-11-09

移动端工具栏、提示条与笔记内容刷新。

### Fixed

- 移动端编辑器正文类型按钮不再显示长文本 “Paragraph/正文”，改为紧凑的 ¶；工具栏保持单行，更多格式 “…” 不再被挤到第二行。
- 移动端提示条恢复单行操作布局：关闭按钮固定在提示条最右侧，不再被 100% 宽度的操作区推到下方。
- 从笔记列表重新打开当前笔记时，会对比最新版本号/标题/正文并刷新编辑器，解决列表已更新但内容页仍是旧内容的问题。

### Added

- `tests/manual/note-refresh-regression.mjs`：列表重开笔记后必须显示服务端最新正文。
- 提示条回归新增移动端单行/关闭按钮位置断言。

## [0.1.14] — 2026-11-09

站点页头统一、按钮悬停与联系邮箱修正。

### Changed

- 新增共享 `SiteHeader` / `SiteFooter`：首页、关于页、隐私政策、服务条款使用同一套站点导航与页脚，不再各自维护独立头部。
- 新增 React `/about` 页面并复用主站 header/footer；旧 `/about.html` 仅保留到 `/about` 的重定向。
- 公开联系邮箱从 `noreply@360note.com` 改为 `contact@360note.com`（页脚、关于、找回密码、隐私政策）。

### Fixed

- 绿色主按钮作为链接时，`a:hover` 覆盖文字颜色，导致悬停后文字与背景同色“消失”。主按钮/危险按钮/soft 按钮 hover 现在显式保持可读文字色。
- 移除不再使用的独立 about.html 内联样式与 legal-nav。

## [0.1.13] — 2026-11-09

空间图标输入框改为正方形。

### Fixed

- 设置 → 空间 → 当前空间：图标输入框改为 36×36px 正方形，与 36px 输入/按钮高度对齐，不再横向占位。

## [0.1.11] — 2026-11-09

分享清理、磨砂头部与空间设置布局。

### Added

- 已撤销分享右侧增加“删除记录”按钮，可永久移除该行，不再挤占正常分享列表。

### Changed

- 移动端模态窗口统一四角圆角，不再出现上圆下方。
- 公开分享页与设置页顶部 header 改为真正的磨砂玻璃：68% 暖纸底 + 18px backdrop blur + 轻微层级阴影；设置页 header 覆盖滚动内容，内容从下方穿过。
- 公开分享页移动端“创建你的 360笔记”按钮固定右对齐。
- 设置 → 空间概览：最左侧空间图标顶部对齐；个人/团队图标紧跟空间名称，不再被推到最右；切换按钮独立右对齐。

### Fixed

- 移动端模态底部直角、分享页 header 无磨砂、设置 header 无磨砂。
- 分享页移动端 CTA 靠左、空间概览图标/类型图标/按钮错位。

## [0.1.10] — 2026-11-09

编辑器反馈、图片上传、新建笔记与移动端分享体验。

### Added

- 图片上传在编辑器中原来的图片位置显示进度条：文件到达、上传百分比、失败原因都留在原位；失败可重试或移除。
- 上传改用 XHR，支持真实字节进度、10 分钟超时、网络错误/超时/服务端错误的明确提示。
- 上传前检查图片格式与大小；服务端拒绝 HEIC/HEIF 等浏览器无法显示的图片并给出可操作提示。

### Changed

- 新建笔记打开时标题为空并自动聚焦，占位符显示带日期时间的建议标题（如“未命名笔记 20261109133256”）；用户不填写时自动保存这个带时间戳的标题，连续新建也能区分。
- 编辑器顶部提示条改为统一 flex 布局：消息左、操作居中偏右、关闭按钮最右；桌面单行，移动端操作换行到右侧。
- Toast 从深色独立样式改为主站暖纸 surface、8px 圆角、彩色图标块，与卡片和提示条一致。
- 已有分享重排为：分享链接作为首要信息，右侧固定复制/删除操作；下方依次显示权限、创建时间，到期时间与浏览次数同一行。
- 公开分享页移动端隐藏复制链接和打印按钮，减少顶部占用；编辑按钮（若有）保留。
- 平板 761–900px 的设置导航改为四列网格，避免横向滚动藏起“关于”等入口。

### Fixed

- 图片上传无进度、失败无原因、不知道数据在哪的问题。
- 编辑器提示条关闭按钮/操作按钮错位。
- 新建笔记必须先删掉“未命名笔记”才能输入的问题。
- 移动端分享页顶部按钮拥挤、已有分享主次不清、链接图标过小的问题。
- 设置页 768px 导航最后一项超出视口的问题。

## [0.1.9] — 2026-11-09

移动端分享列表重排、列表密度与短分享链接。

### Changed

- 分享链接 token 从 24 字节（32 字符）缩短为 12 字节（16 字符，96 位熵）；新链接更短，旧链接继续有效。
- “已有分享”改为卡片式布局：链接图标 30px，权限/密码状态一行，创建时间、到期时间、浏览量各占一行，复制/撤销按钮在窄屏下单独一行。
- 团队成员行在移动端把角色/移除操作放到第二行，邮箱与加入时间获得完整宽度。
- 邀请成员表单在移动端改为纵向全宽，邮箱、角色和创建按钮不再挤在同一行。
- 审计日志在移动端改为“时间 / 操作人 / 操作 / IP”纵向排列，不再使用固定列宽挤压文本。

### Fixed

- 移动端分享列表时间、浏览量与图标挤在一起，链接图标过小的问题。
- 团队成员、邀请表单、审计日志在窄屏下的同类换行/挤压问题。

## [0.1.8] — 2026-11-09

空状态操作居中与全站对齐检查。

### Fixed

- 笔记列表空状态的“新建笔记”“清除搜索”操作组改为居中，桌面和移动端一致。
- 空列表、空编辑器、设置区空状态的通用操作组统一 `justify-content: center` 和 `flex-wrap`，按钮较多或窄屏时仍居中换行。
- 新增 `tests/manual/centering-regression.mjs`：覆盖搜索空状态、空文件夹、移动端空文件夹、空编辑器和公开分享失效页 CTA 的居中对齐。

## [0.1.7] — 2026-11-09

门面与细节一致性：首页演示、侧栏高度、主题预览、新用户引导与邮件。

### Changed

- 新注册用户只生成一篇欢迎笔记，并把 Markdown 速查、快捷键、整理与分享说明合并进这篇笔记；删除“关于 360note 的设计”示例。
- 侧栏文件夹与标签改为共用一个可滚动区域，不再各自固定 38vh/24vh；两者按内容共享剩余高度，空间不足时整体滚动。
- 首页移除“附件已加密”“随时导出”浮动标签及其样式。
- 首页演示窗口重做为接近真实三栏应用：官方 logo、空间切换、导航、文件夹/标签、搜索框、新建按钮、笔记摘要/日期/标签、编辑器面包屑与保存状态。
- 主题预览卡改为三栏真实界面缩略图，浅色/深色/跟随系统使用各自准确的背景、侧栏、列表与正文色；不再用几条抽象线表示。
- 编辑宽度预览改为比例展示：窄栏为容器 72%，宽栏占满内容宽度。
- 邮件模板沿用原布局，但圆角从 16/12/9px 收紧到 10/8/6px；配色改为主站暖纸底、绿 accent、石墨文字；使用官方中英文 wordmark PNG，并补充 CJK 字体回退。

- 主题卡片与实际主题不一致、宽栏预览未全宽的问题。
- 首页演示列表与真实产品结构不符、浮动标签像错位元素的问题。
- 邮件模板遗留的旧金色/棕色系和文本 logo 与主站不一致的问题。

## [0.1.6] — 2026-11-09

可靠性、离线策略、邀请身份与可操作性收敛。

### Added

- 后台任务启动恢复：服务重启后，遗留的 queued/running 任务会明确标记为失败并提示重试，不再永久停在“处理中”。
- 任务原子领取：`claimJob` 使用 `status='queued'` 条件更新，重复调度或并行 worker 不会执行同一任务两次。
- 备份任务幂等：`backups.job_id` 唯一索引，重复执行同一 job 返回同一份备份；写入后解密并校验 ZIP 清单与数量。
- PostgreSQL 集成测试：注册/登录、空间隔离、笔记、备份往返、邀请身份迁移与并发重复邀请。
- 后台任务恢复测试与完整备份恢复演练（创建 → 预览 → 下载 → 删除 → 上传 → 合并恢复 → 校验正文）。
- 核心 Playwright 测试：桌面创建/编辑/刷新/搜索，移动端编辑器无横向溢出。
- 数据设置新增“本机离线数据”说明与手动清除入口；请求浏览器持久化存储权限，降低离线正文被回收的概率。
- 分享对话框显示当前分享指向的版本号与最后更新时间。
- 笔记面包屑首项显示当前空间名称；侧栏导航、文件夹和标签增加 `aria-current` / `aria-expanded` 语义。
- 可选 `BOOTSTRAP_ADMIN_EMAIL`：把新实例首个管理员固定到指定邮箱，避免公开注册被抢注管理员。

### Changed

- 邀请绑定改为：已知接收人按用户 ID 绑定，邮箱变更后仍可接受；未注册邮箱才按邮箱匹配。旧地址的新账号不能继承邀请。
- 邀请接受/拒绝/列表统一使用同一身份规则；同一空间同一邮箱只允许一条 pending 邀请（数据库唯一索引 + 409）。
- 保存失败横幅明确提示“正文和草稿已保存在这台设备”，并保留重试/复制正文操作。
- 搜索结果为空时提供“清除搜索”和“新建笔记”两个下一步。
- 侧栏操作热区从 22px 提升到 24px；移动端 toast 距底部安全区 18px；标题占位文字改为非斜体。
- 主题预览卡改用 `.theme-option` / `.theme-preview` CSS 变体与 token，移除硬编码内联颜色。
- “从文件夹菜单新建”改为在该文件夹下创建子文件夹，并在父节点下内联编辑；根级加号仍创建根文件夹。
- 清理未使用的营销页/旧 hero/auth 响应式样式。

### Fixed

- 并发保存的版本条件更新、2FA/恢复码/邮箱验证码/登录失败计数/邀请接受等原子性回归由测试覆盖。
- 邀请重复发送的 check-then-insert 竞态。
- 已知邀请人改邮箱后邀请“消失”或无法接受的问题。
- 备份写入后半损坏文件仍可能被登记的问题（现在先校验后发布）。
- 分享版本不明确、搜索空状态无行动、离线数据位置不透明。

## [0.1.5] — 2026-11-08

分享、表格、导出、保存并发与视觉收敛。

### Added

- 分享对话框在已有有效链接时提示“访客看到最新版本”，创建分享后 toast 说明后续编辑会同步。
- 表格上下文栏：上方/下方加行、左侧/右侧加列、删除当前行/列、删除整表。
- 信息面板附件删除（两次点击确认）。
- 空间概览与个人/团队空间说明；创建弹窗可选择个人/团队。
- 新增 demo 账号与覆盖中英文/Markdown/富文本/表格/图片/附件/标签/文件夹/评论/版本/分享/回收站/备份的演示数据；凭据不写入仓库。
- 分享页专用打印样式：A4、完整日期/打印时间、隐藏评论和界面操作。

### Changed

- PDF 导出改为 A4、10.5pt 正文、22pt 标题，接近编辑器在合适宽度下的阅读效果。
- Markdown 模式移除顶部提示条和 `.source-footer`，只保留 `.editor-footbar`。
- 聚焦模式移除右上悬浮按钮，底栏按钮切换“聚焦/退出聚焦”。
- 编辑模式持久化，切换笔记或离开后仍保留富文本/Markdown 选择。
- 普通菜单改为内容自适应（140–360px）；Dropdown 使用真实触发按钮定位；退出登录菜单只容纳最长选项。
- 新建笔记按钮改为白底细边框、蓝色图标，降低视觉重量。
- 删除侧栏“已同步”和移动端同步点，只保留编辑器右上保存状态；底部只保留字符数。
- 历史“保存版本”按钮由虚线改为实线。
- 头像改为圆形白字；品牌默认改为 `360note.` 文字标识（蓝色句点），折叠侧栏才显示 `N.`；favicon/PWA/apple-touch 同源。
- 账户页显示名称/邮箱/保存按钮同列，控件统一 36px。
- 切换板块立即清空旧列表并显示 loading skeleton，避免延迟显示不匹配内容。

- 自动保存并发导致同一 baseVersion 的 PATCH 竞争和大量冲突副本：保存改为单飞 + 合并排队；冲突内容改存版本历史（第六轮）。
- 上传附件/导出 PDF 时持续编辑产生冲突副本。
- 删除附件后信息面板继续显示旧附件。
- 历史保存版本虚线不符合控件规范。
- 富文本/Markdown 模式每次进入笔记被重置。
- Banner/Toast 图标与文字对齐不一致；安全页提示与技术标题间距过窄。
- 分享页打印缺少专用版式与完整时间格式；打印保留完整发布/打印时间，更新时间使用相对时间。
- 深蓝海军色 toast/代码表面改为暖炭色；附件列表只显示仍被正文引用的附件。
- 移除移动端底部的重复新建按钮，顶部新建按钮与桌面端统一样式；移动栏只保留笔记/搜索/收藏/设置。
- 头像改为单字母圆形标记；分享页增加复制链接；空间命名弹窗焦点稳定。
- 空间创建弹窗可选择“个人空间/团队空间”；个人空间可创建多个，删除时至少保留一个空间。
- 修复 Modal 焦点 effect 依赖每次渲染变化的 `onClose`，避免空间命名/分享/上传弹窗每个字符失去焦点或闪烁。
- 用户菜单移除重复的账户/外观/安全入口，只保留退出登录。
- 移动端底部新建按钮最终移除，新建仅保留顶部与桌面同款按钮；快速栏四等分。（第七轮整体移除底部快速栏。）
- 清理测试登录通知，铃铛未读蓝点与真实未读状态一致。
