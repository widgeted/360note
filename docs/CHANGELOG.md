# Changelog

All notable changes to 360note are documented here.  
Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions use [Semantic Versioning](https://semver.org/).

## [0.1.38] — 2026-11-10

iOS 安装提示图标排版。

### Fixed

- “更多”“共享”“添加到主屏幕”图标分别放在对应文字前方，而不是放在“点击”前方。
- 每个内联图标前后都有明确空格，避免文字与图标粘连。

## [0.1.37] — 2026-11-10

安装提示图标与空间菜单对齐修正。

### Changed

- iOS Safari 安装提示改为单段文字，内联“更多”“共享”“添加到主屏幕”三个图标，不再拆分步骤行。
- 展开侧栏的空间切换菜单改为右对齐，跟随右侧向下箭头；宽度与触发器一致，长名称换行。
- 收起侧栏仍保持左对齐、自适应宽度，避免窄触发器把长名称挤出去。
- 更新设计系统文档中的空间菜单对齐规则，避免继续按旧的“全宽触发器统一左对齐”执行。

## [0.1.36] — 2026-11-10

安装提示与移动侧栏微调。

### Changed

- iPhone 安装引导恢复为单行说明，只保留“添加到主屏幕”图标，不再拆成四步多行。
- 移除移动端侧栏的项目阴影，避免暗色蒙层下出现类似屏幕损坏的阴影带。
- 保留侧栏右边框；移动端展开侧栏的导航、文件夹、标签、通知和账户图标整体放大。

## [0.1.35] — 2026-11-10

移动端安装步骤、外观主题与设置导航优化。

### Changed

- iPhone 安装引导改为四步图标说明：右下角“…”→“共享”→“查看更多”→“添加到主屏幕”。
- 移动端主题选项保持三列一排，预览缩小，Monitor/Sun/Moon 图标降到 11px，减少额外占用。
- 移动端设置标签点击后自动滚动到中间；首尾标签自动贴边。
- 移动端展开侧栏宽度与新建笔记列表对齐，并增加右边框和阴影。
- 桌面端收起侧栏后的空间切换菜单改用自适应宽度，长空间名称会换行，菜单背景完整覆盖。
- 登录后应用账户保存的主题偏好；缓存账户主题在首屏提前应用，修复固定浅色仍显示深色的问题。

### Fixed

- 账户主题偏好与本地主题缓存不一致时，移动端启动主题错误。
- 长工作区名称溢出空间切换菜单背景。

## [0.1.34] — 2026-11-10

移动端安装引导、图标语义修正与快捷操作样式。

### Added

- iPhone Safari 与 Android Chromium 等主流移动浏览器增加一次性“添加到主屏幕”引导。
- 已是桌面 App/standalone 模式、桌面设备或微信等内嵌浏览器时不提示。
- 每个浏览器只提示一次；关闭或拒绝后不再出现。
- 补充 iOS 152/167/180 专用主屏幕图标、Web App 元信息与更完整的 PWA manifest。

### Changed

- 编辑器“Markdown 模式/富文本模式”菜单图标随目标模式切换为 `M↓` / `Aa`。
- 管理员“启用账号”改用用户勾选图标，不再使用禁止图标。
- 文件夹和标签“重命名”统一使用铅笔图标；分享“撤销”改用断链图标。
- 移动端笔记列表的收藏/置顶改为两个独立按钮，各自有边框和背景，不再使用渐变遮罩，并给元信息预留右侧空间。

## [0.1.33] — 2026-11-10

分享列表信息压缩。

### Changed

- “已有分享”的权限、创建时间、过期时间和浏览次数合并到一行，窄屏自动换行，减少纵向占用。
- “只读”改用书本图标，浏览次数继续使用眼睛图标，避免两个含义不同的信息使用同一图标。

## [0.1.32] — 2026-11-10

公开评论管理、通知中心、图片说明、自定义模板与备份运维增强。

### Added

- 实例管理新增“公开评论”板块：评论内容、访客昵称、IP、被评论笔记、时间，管理员可删除滥用评论。
- 用户设置新增“评论管理”：查看自己笔记上的评论和自己发表的评论，删除有权删除的评论。
- 通知中心新增“全部消息”面板，分页展示全部历史通知；未读状态改为服务端回读，修复已读后绿点仍显示的问题。
- 图片支持可选 alt 与说明文字；说明会以弱化样式显示在分享页/打印稿图片下方，未填写时不占额外空间。
- 新增自定义模板与变量：`{{date}}`、`{{time}}`、`{{datetime}}`、`{{title}}`、`{{user}}`、`{{workspace}}`、`{{folder}}`。
- 存储管理新增对象存储文件浏览：查看对象、大小、时间，支持校验、下载和工作区备份“恢复为副本”。
- 新增整站备份恢复演练：可手动立即演练，也可按小时频率自动演练；记录最近结果与错误。
- 工作区备份按附件 SHA-256 去重，同一备份中相同文件只存一份。

### Changed

- 新建笔记不再把 `202611101454` 时间戳写入标题，默认标题保持短文本，避免移动端标题占两行。
- 备份、恢复、对象存储测试/迁移/校验/恢复、邀请邮件与账户导出等操作写入操作日志；失败时记录错误原因。
- 对象存储已有远端附件时，连接身份校验同时覆盖 region，防止只改区域导致附件失联。

### Notes

- 增量备份目前采用“同一备份内容去重”；链式增量（依赖多份历史备份）未强行上线，避免恢复链不可靠。下一步可单独设计链式增量与校验。
## [0.1.31] — 2026-11-10

公开链接表格、访客评论管理与设置入口调整。

### Changed

- 实例管理“公开链接”改为表格：链接、用户、权限、类型、过期时间、次数；每页 50 条，可翻页。
- 去除单独的“打开”列，直接点击链接即可打开；密码链接仍要求密码。
- 笔记作者可以删除匿名访客评论；评论作者仍可删除自己的评论。
- 笔记页侧栏的“设置”入口移入用户名右侧“…”菜单，放在“退出登录”“退出并清除本机数据”上方。

### Fixed

- 评论删除权限提示区分“自己的评论”和“笔记作者删除匿名访客评论”。

## [0.1.30] — 2026-11-10

按钮体系统一与最近改动的深度回归。

### Changed

- 实心主按钮、红色危险按钮、浅色按钮和红色文字按钮统一补上 1px 边框；危险按钮增加与主按钮一致的轻微阴影，尺寸不再显得比其他按钮大。
- 红色按钮在深色主题使用深色文字与更深的边框，保证对比度和视觉重量一致。
- 概览中的“附件存储”统计改名为“附件数据量”，避免与“本机附件占用”混淆。
- 打印分享页时隐藏正文后的装饰分割线。

### Fixed

- 对象存储连接身份校验补上 region；已有远端附件时修改 region 会被拒绝，避免签名区域变化导致附件失联。

### Verified

- 危险按钮与次要按钮在模态框中高度、圆角、字号一致，边框均为 1px。
- 生产实例执行对象存储迁移清理后，整站备份仍能包含全部远端附件并自动上传。
- 移动端单击笔记、列表分隔线、分享页分割线、管理员完整链接均在最终构建上复核。

## [0.1.29] — 2026-11-10

移动端笔记列表、分享页分隔线与管理员链接可读性。

### Changed

- 移动端笔记列表每一项增加细分割线，列表层级更清楚。
- 触屏设备不再依赖 hover 显示快捷操作，快捷操作常驻低透明度，首次点击笔记即可进入内容页。
- 实例管理“公开链接”改为整行显示完整 URL，不再省略或压缩成一列窄字；元数据换行排列。
- 管理员整站备份文件名、分享页长附件名允许换行，避免溢出。
- 分享页正文结束增加统一分割线，附件显示在分割线之后且不再额外加线；底部分割线间距与编辑页一致。
- 移动端分享页底部间距同步收紧。

### Fixed

- 移动端首次点击笔记只激活、不进入内容页的问题。
- 管理员分享链接在中等宽度下被压缩到几像素宽、逐字换行的问题。

## [0.1.28] — 2026-11-10

存储管理归位、上传即时预览与阅读区细节修正。

### Changed

- 对象存储与备份副本从用户“数据与备份”移到 **实例管理 → 存储管理**，只对实例管理员开放，作为全站共享能力。
- 实例管理改用服务器设置图标，不再使用安全盾牌图标。
- 编辑器标签栏与正文之间的间距增大，底部线条不再紧贴文字；分享页不受影响。
- 分享页附件区去掉与正文末尾相似的分割线，仅保留间距和“附件”标题。
- 明确说明：附件仍通过站点域名加密代理访问，URL 显示 360biji.com/360note.com 属于正常设计，实际文件保存在对象存储。

### Fixed

- 图片上传后等待缩略图生成再返回，并增加缩略图内存缓存，上传完成后立即显示，不再依赖后续刷新。
- 冷启动后首次查看缩略图仍可能有一次对象存储读取，之后由缓存直接返回。
- 启用附件对象存储成功后自动清理已校验的本机副本，并提供“清理本机副本”手动入口；本机占用可降为 0。

## [0.1.27] — 2026-11-10

对象存储附件、存储用量与整站备份自动上传。

### Added

- S3 兼容对象存储可同时用于备份副本与笔记附件；连接配置、连接测试、用量统计集中在“数据与备份”。
- 启用附件对象存储时自动迁移已有附件，按同目录、同名称、同大小跳过已存在的远端文件；停用前逐个取回并校验，全部成功后才切回本机，可选择清理远端副本。
- 实例概览和数据设置展示本机附件占用、对象存储附件/备份占用。
- 整站备份自动上传到对象存储，列表显示上传状态并支持失败重试；整站备份会包含仅存在于对象存储的附件。
- 新增 `tests/manual/object-storage-e2e.mjs`，覆盖上传/读取/缩略图/迁移/回迁/跳过相同文件/删除/整站备份。

### Changed

- 附件链接继续固定为 `/api/attachments/:id/content`，切换存储后端不改写笔记正文。
- 附件删除同时清理本机与远端副本，避免迁移后残留。
- 有远端附件时禁止修改连接配置，必须先停用并取回，防止附件失联。

### Fixed

- 迁移完成与启用标记之间的状态读取竞态。
- 对象存储连接测试在部分兼容实现上的列表兼容性。

## [0.1.26] — 2026-11-10

响应式标题、自动刷新、整站备份与实例管理分栏。

### Changed

- 笔记标题高度随窗口宽度自动重算，缩小窗口换行时不会截断第二行。
- 窗口重新获得焦点/页面恢复可见时自动刷新笔记列表、文件夹和标签，减少手动刷新。
- 移动端编辑器格式条锁定为横向滚动，只允许左右滑动，不再上下抖动。
- 关于、隐私、条款等公共页面和设置标签切换后自动回到顶部。
- 备份文件扩展名从 `.nhbackup` 改为更短的 `.3nb`；旧文件仍可下载/恢复。
- 实例管理拆分为概览、用户管理、公开链接、操作日志四个板块。
- 概览新增整站备份：自动开关、频率、保留份数、手动创建/下载/删除；包内含数据库 dump 与加密附件。
- 管理员分享链接列表使用昵称、紧凑列和更长链接区域。

### Fixed

- 中文相对时间缺少数字（如“分钟前”）。
- 管理员导出入口移除，导出改为用户自助且每 24 小时最多一次。

## [0.1.25] — 2026-11-09

自助数据导出、相对时间与管理表格修正。

### Changed

- 数据导出改为用户自助：设置 → 账户 → 我的数据，每 24 小时最多一次；下载链接只发到用户本人邮箱，管理员不再能代替用户导出。
- 管理员分享链接审查：所有者显示昵称而非邮箱；链接列加宽，权限/类型/有效期/浏览量列收紧。
- 用户管理操作 Dropdown 不再固定表尾，宽度按内容自适应。
- 相对时间修复：中文“5 分钟前 / 2 小时前 / 3 天前”不再丢失数字。
- 横向滚动的工具栏、标签栏、移动设置导航增加左右边缘渐隐提示。
- 无标签时不再显示“还没有标签”，只保留添加标签入口。

### Fixed

- 用户管理“最后登录”缺少数字。
- 分享链接审查展示用户邮箱而非昵称。

## [0.1.24] — 2026-11-09

管理员分享审查与操作菜单。

### Added

- 实例管理新增“分享链接”列表：只展示当前有效分享的链接、所有者、权限、是否需密码、到期时间、浏览量。
- 公开分享链接可直接打开；需要密码的链接管理员仍不能绕过；列表不包含笔记正文。
- 管理员可生成用户导出链接（后续 0.1.25 改为用户自助导出）。

### Changed

- 用户管理操作改为 Dropdown，固定在表格右侧，避免横向滚动后找不到操作。
- 表头单行显示；管理员日志用户名/操作/IP 单行省略并悬停完整显示。
- 横向工具栏、标签栏、移动端设置导航增加左右渐隐提示。
- 无标签时不再显示“还没有标签”。

## [0.1.23] — 2026-11-09

用户管理菜单、滚动提示与合规导出。

### Changed

- 用户管理“操作”改为 Dropdown：禁止/允许分享、停用/启用账号、退出设备，减少表格占用。
- 用户表头保持单行；“空间/笔记、附件存储、会话、最后登录”等列不换行。
- 右侧信息栏无标签时不再显示“还没有标签”，只保留添加标签 token。
- 横向滚动的工具栏、标签栏、移动端设置导航增加左右边缘渐隐，提示还有内容。
- 管理员可为用户生成数据导出，下载链接只发送到该用户邮箱；管理员界面不展示导出内容。

### Added

- 管理员合规导出：按用户自有空间生成 `.nhbackup` 包，7 天有效下载链接，邮件投递；导出动作写入日志。
- 右侧栏/编辑器标签 token 内联输入与推荐标签多行布局。

## [0.1.22] — 2026-11-09

合规管理、日志分页、标签内联编辑与邮件安全。

### Added

- 管理员可禁止用户创建分享（并撤销其现有分享）、停用/启用账号（立即撤销会话与分享）。
- 新增注册 IP 限制：阻止指定 IP 注册新账号，已有账号登录不受影响。
- 实例管理“日志”支持分页浏览；用户名/操作/IP 单行省略，悬停显示全文。
- 邮件发送新增保留域名拦截（`.invalid`/`.test`/`.example`/`localhost` 等），并加入单元测试与文档红线。

### Changed

- 编辑器与右侧栏添加标签改为 tag token 内联输入：Enter 保存并继续下一个空白标签，最后一个空白标签在失焦时不保存；推荐标签一行多个。
- 编辑器标签栏在短内容时固定在底部，长内容时随正文滚动。
- 标签统一为字面 `#` + 名称的 `.tag-token`，侧栏/信息栏/编辑器一致；设计规范同步更新。
- 管理员用户表增加空间/笔记/附件/会话/2FA/停用状态及限制操作。

### Reliability

- 收藏/置顶/标签等元数据更新不再增加文档版本，避免编辑中伪冲突。
- 移除自动“其他设备合并”提示；有未保存内容时后台刷新不覆盖正在编辑的文字。

## [0.1.21] — 2026-11-09

笔记稳定性、历史版本、标签与管理员能力。

### Reliability

- 收藏、置顶、移动、标签等元数据更新不再消耗笔记文档版本，不再导致编辑中的笔记出现伪冲突。
- 编辑器在本地有未保存内容时，不会用后台刷新内容覆盖用户正在编辑的文字。
- 移除“已加载其他设备合并后的最新内容”自动提示条；自动合并与冲突不再弹出 toast，冲突只保留可操作的提示条。
- 修复从列表重新打开笔记时可能显示旧正文的问题（比较版本/标题/正文后刷新）。

### Editor

- 移动端移除“聚焦模式”入口；桌面保留。
- 桌面右侧信息面板改为与移动端一致的抽屉，不再挤压编辑区/Markdown 切换栏。
- 历史版本改为折叠面板：点击版本在原行展开预览与恢复操作，不再在列表底部显示单一预览。

## 2026-11-09 — 并发、TOTP、备份与本地缓存加固

- 笔记保存改为事务内 `SELECT … FOR UPDATE` + `WHERE version = locked.version` 条件更新；并发保存只有一个提交，另一个返回 409。冲突响应包含当前版本。
- 首次注册使用 PostgreSQL 事务级 advisory lock 串行化“用户数检查 + 创建”，并发首次注册只产生一个管理员。
- TOTP 时间步使用 `totp_last_step < step` 原子消费；备用码使用 `used_at IS NULL` 原子 UPDATE。并发登录同一时间步/备用码只有一个成功。
- 启用 2FA 也改为条件更新，避免并发启用覆盖备用码。
- 邮箱验证码消费改为 `consumed_at IS NULL` 原子更新；邀请接受改为 `status='pending' AND expires_at > now()` 条件更新。
- 备份 ZIP 解析增加条目数、单条目、解压总量、压缩比和结构校验；恶意备份在解压前被拒绝。
- PDF 导出移除外部图片，避免 Chromium 被笔记内容诱导访问内网地址。
- 退出登录新增“退出并清除本机数据”选项；切换账户自动清空上一账户的 IndexedDB 笔记、草稿、outbox 与 workspace 快照。
- nginx 使用 Cloudflare 真实客户端 IP 覆盖 X-Forwarded-For，Fastify 仅信任本机代理，避免限流/审计 IP 伪造。
