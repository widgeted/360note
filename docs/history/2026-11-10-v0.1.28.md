# 2026-11-10 — v0.1.28 存储管理归位与上传即时预览

## 界面与权限

- 对象存储/备份副本配置移入 **实例管理 → 存储管理**；普通用户不再看到任何实例级存储入口。
- 实例管理导航图标从安全盾牌改为服务器设置图标。
- 编辑器标签栏改为独立顶部边线，并增加 26px 间距，避免底部线条贴住正文。
- 分享页附件区移除全宽分割线，避免与正文结束线混淆。

## 上传与对象存储

- 图片上传接口等待缩略图生成完成后再响应，避免客户端拿到的缩略图 URL 与异步上传竞态。
- 缩略图增加 64MB 进程内 LRU 缓存；上传后首次预览可直接命中，实测从约 3.1 秒降到约 12 毫秒。
- 附件 URL 继续固定为站点域名下的 `/api/attachments/:id/content`；对象存储是后端存储，不暴露 S3 域名。这是鉴权与链接稳定的设计，不是“仍在本地”。
- 存储管理页面补充说明：URL 显示 360biji.com/360note.com 为正常现象。

## 验证

- 上传 1600×1200 JPEG：上传 1.6 秒，首张缩略图 12ms / 8ms / 6ms。
- 数据页确认不再显示实例级存储配置；存储管理 tab 可见并通过 390px 响应式检查。
- 编辑器标签栏 margin-top 26px、分享页附件区 border-top 0。
- 类型检查、构建、生产重启通过。
