# 2026-11-09 — v0.1.25 自助导出与管理表格修正

## 本次变化

- 数据导出改为用户自助：设置 → 账户 → 我的数据，每 24 小时最多一次；链接只发送到本人邮箱，管理员不能代替导出。
- 管理员分享链接审查：所有者显示昵称，链接列加宽，权限/类型/有效期/浏览量紧凑；公开链接可打开，密码链接不可绕过。
- 用户管理操作 Dropdown 宽度自适应，不再固定在表尾。
- 中文相对时间恢复数字：5 分钟前 / 2 小时前 / 3 天前。
- 横向滚动工具栏/标签栏/移动设置导航增加边缘渐隐。
- 无标签时不再显示“还没有标签”。

## 验证

- 管理员用户表最后登录显示“7 分钟前”；操作菜单无导出项；分享列表所有者显示昵称。
