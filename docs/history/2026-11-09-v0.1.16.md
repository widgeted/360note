# 2026-11-09 — v0.1.16 图片缩略图与原图按需加载

## 本次变化

- 图片上传后由 `sharp` 生成最长边 960px、quality 72 的 WebP 缩略图。
- 编辑器与公开分享页默认显示缩略图，使用 `loading=lazy` / `decoding=async`。
- 点击缩略图打开全屏预览，只有这时才请求原图；预览可新标签打开原图。
- Markdown 始终保存原图 URL，缩略图只影响显示，不影响导出、分享或迁移。
- 旧附件首次请求缩略图时自动补生成；删除附件同步删除缩略图。
- 缩略图沿用附件读取权限、ETag 和私有缓存。

## 验证

- 1600×1200 JPEG：原图约 50KB，缩略图 960×720 WebP 约 6KB。
- 编辑器图片 `src` 带 `?thumb=1`，`data-original-src` 为原图；Markdown 不含 thumb 参数。
- 公开分享页同样先加载缩略图，点击后加载原图。
- 上传进度、失败重试/移除、安全审计 66/66 通过。
