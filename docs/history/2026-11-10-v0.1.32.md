# 2026-11-10 — v0.1.32 评论、通知、模板与备份运维

## 评论

- 新增 `comments.ip` 迁移；公开访客评论写入客户端 IP。
- 管理端“公开评论”：内容、访客昵称、IP、笔记标题、时间，分页 50；管理员可删除访客评论。
- 用户端“评论管理”：自己笔记上的评论和自己发表的评论，按权限显示删除。
- 删除规则保持：作者删自己的；笔记作者删匿名访客；其他协作者 403。

## 通知

- `/api/notifications` 支持 `limit/offset/total`。
- 通知中心新增“全部消息”模态面板，分页浏览全部历史。
- 标记已读后重新从服务端拉取 unread；修复绿点残留和“已读但显示未读”。

## 图片说明

- 图片节点支持 alt 与 title/说明；编辑器灯箱提供“图片说明”入口。
- Markdown 保存为 `![alt](src "caption")`。
- 分享/打印渲染为 `figure.prose-figure` + `figcaption`；未填写不生成 figure。
- 服务端导出 HTML/PDF 同步支持。

## 模板

- `templates` 表与 `/api/templates` CRUD。
- 设置 → 模板支持创建、编辑、删除、变量插入。
- 新建笔记模板弹窗同时展示内置模板与自定义模板。
- 变量：date/time/datetime/title/user/workspace/folder。

## 标题

- 新建笔记标题不再写入 `202611101454` 时间戳；默认使用短标题“未命名笔记”。
- 自定义模板标题不会被 fresh-note 逻辑清空。

## 日志

- 增加备份创建/恢复/上传失败、对象存储测试/迁移完成/校验/恢复、邀请邮件、账户导出失败等审计事件。
- 对象存储恢复、整站备份演练、公开评论删除均有审计。

## 备份与对象存储

- 工作区备份按附件 SHA-256 内容去重，同一备份中重复文件只存一份。
- 对象存储文件浏览、校验、下载、工作区备份恢复为副本。
- 整站备份恢复演练手动/自动执行，记录最近结果和错误。
- 链式增量备份未上线，避免恢复链依赖风险；内容去重已生效。
