## 主要变化

### 可靠性

- 后台任务改为原子领取；服务重启时把遗留 `queued/running` 任务标记为失败并提示重试。
- 备份任务使用 `job_id` 幂等；写入后解密、预览并核对笔记/附件数量，校验失败会删除半成品。
- 新增 PostgreSQL 集成测试、任务恢复测试和完整备份恢复演练。
- 自动备份复用同一校验路径。

### 身份与注册

- 邀请接收人已知时按用户 ID 绑定，改邮箱后仍可接受；旧邮箱的新账号不能继承邀请。
- 同一空间/邮箱只允许一条 pending 邀请，新增数据库唯一索引并处理并发 409。
- 新增可选 `BOOTSTRAP_ADMIN_EMAIL`，把新实例首个管理员固定到指定邮箱。

### 可操作性与离线

- 面包屑首项显示当前空间；分享对话框显示当前版本和更新时间。
- 搜索空状态提供“清除搜索”和“新建笔记”。
- 保存失败时明确告知正文/草稿在本机，保留重试与复制。
- 数据设置新增离线数据说明与清除入口；申请浏览器持久化存储。
- 侧栏/文件夹/标签增加 `aria-current`、`aria-expanded`，文件夹菜单按名称标注。

### 外观

- 首页 header 全宽、内容仍为 1180px；浮动标签改为磨砂透明并轻微浮动；移除安全卡右上角渐变。
- 文件夹菜单“新建子文件夹”落在所选文件夹下；根级加号仍创建根文件夹。
- 主题预览卡改为 CSS 变体；侧栏热区 24px；移动端 toast 18px；标题占位非斜体。
- 清理未使用的营销/旧 hero/auth 响应式 CSS。
