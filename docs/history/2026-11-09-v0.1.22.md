# 2026-11-09 — v0.1.22 合规管理、日志与标签内联编辑

## 管理员

- 用户可被禁止分享、停用/启用账号；停用会撤销会话和现有分享。
- 注册 IP 限制：支持添加/解除 IP，阻止新账号注册，不影响已有账号登录。
- “全局审计”改为“日志”，支持 50 条/页分页；用户名、操作、IP 单行省略，悬停显示全文。
- 用户表展示空间/笔记/附件存储/会话/2FA/停用状态，支持角色、分享、停用、退出设备操作。
- 管理员仍不能读取用户笔记正文。

## 标签

- 编辑器和右侧栏标签改为 token 内联输入：Enter 保存并继续下一个空白 token，失焦时最后空白 token 不保存。
- 推荐标签一行多个自动换行。
- 编辑器标签栏在短内容时固定底部，长内容随正文滚动；全站统一 `#名称` `.tag-token`。

## 邮件安全

- 发现测试注册触发欢迎邮件到 `@invalid.local`。
- `sendMail` 在 SMTP 前拦截 `.invalid`/`.test`/`.example`/`.localhost` 与 `invalid.local`。
- 新增单元测试，并把“禁止向任何未验证/不存在地址发送测试邮件”写入 `tests/manual/README.md`、`docs/QUALITY.md`、`docs/OPERATIONS.md`。

- 管理员限制、IP 封锁、日志分页、笔记稳定性、刷新、响应式审计、Playwright 全部通过。
