# 2026-11-10 — v0.1.34 安装引导与图标一致性

## PWA 安装引导

- 新增 `PwaInstallPrompt`，仅在移动设备、非 standalone、非内嵌浏览器、路径为 `/app` 时考虑展示。
- iOS Safari：10 秒后展示分享/添加到主屏幕说明。
- Android Chromium 系：捕获 `beforeinstallprompt`，展示安装按钮。
- 使用 `nh-pwa-install-v1` 持久记录 shown/installed/dismissed，之后不再提示。
- manifest 增加 id/lang/display_override/start_url=/app；补齐 152/167/180 Apple 图标和 Web App meta。

## 图标一致性

- 编辑器模式切换：目标为 Markdown 显示 M↓，目标为富文本显示 Aa。
- 管理员启用账号：Ban → UserCheck。
- 文件夹/标签重命名：Folder/Hash → Pencil。
- 分享撤销：Trash → Link2Off；确认态仍显示 Trash。

## 移动端快捷操作

- 移除 `.note-item-quick-actions` 的渐变背景和左侧遮罩。
- 收藏/置顶各为 26px 独立按钮，1px 边框、独立背景、5px 间距。
- 移动端 note-item-meta 右侧预留 62px，避免图标压住标签/时间。

## 验证

- iPhone Safari 模拟：10 秒出现说明，关闭后刷新不再出现。
- Android 模拟：出现安装按钮，原生拒绝后隐藏。
- standalone 与桌面环境：不出现。
- 移动端快捷操作：background none、padding-left 0、两个独立 26px 按钮。
