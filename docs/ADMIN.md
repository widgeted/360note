# 360note 实例管理员指南

入口：以实例管理员身份登录后进入 **设置 → 实例管理**。

实例管理分为五个板块：**概览、存储管理、用户管理、公开链接、操作日志**。

## 能看到的运行数据

- 用户、空间、笔记、附件数量；
- 附件存储总量与数据库大小；
- 有效分享链接、活动会话；
- 待处理任务、过去 24 小时失败任务；
- 最近一次备份时间；
- 进程运行时间、内存、Node 版本；
- 注册模式、OCR/AI 是否启用、备份保留天数。

## 能管理的用户数据

管理员可以：

- 查看账户元数据：邮箱、昵称、角色、2FA 状态、最后登录时间、创建时间；
- 查看每个用户的空间数、笔记数、附件存储、活动会话数；
- 调整用户角色（普通用户 / 管理员）；
- 强制退出某个用户的全部设备；
- **禁止分享**：阻止该用户创建新分享链接，并撤销其现有有效分享；
- **停用/启用账号**：停用后立即撤销全部会话、禁止登录，并撤销其分享；
- **用户自助导出**：用户在“设置 → 账户 → 我的数据”生成自有空间 `.3nb` 包，下载链接只发送到本人邮箱，7 天有效，每 24 小时最多一次；管理员不能代替用户导出或查看内容。
- 查看当前有效分享链接清单：链接、所有者、权限、是否需密码、到期时间和浏览量。公开链接可直接打开；需要密码的链接仍需密码，管理员不能绕过；不展示笔记正文。
- 查看分页“日志”（谁在什么时候做了什么，可翻页浏览完整历史）。
- 新增 **注册 IP 限制**：禁止指定 IP 注册新账号，已有账号登录不受影响。

管理员**不能**通过实例管理接口读取用户笔记正文。笔记正文、附件、评论等仍需以该用户自己的身份和空间权限访问；这是有意设计的边界，避免“管理员后门”。

## 不能做的事

- 不能查看用户密码、TOTP 密钥或恢复密钥明文；
- 不能绕过空间成员权限直接打开用户笔记；
- 不能读取已删除用户的私有内容。

## 备份与应急

- 概览里可设置实例级整站备份：是否自动、频率（小时）、保留份数；
- 整站备份包含 `pg_dump` 数据库导出和加密附件，下载为 `.3nb`，恢复需要主密钥；
- 可随时手动创建整站备份并下载；
- 实例管理里可调整工作区备份保留天数；
- 站点级 S3 兼容存储（备份副本与附件）只在这里配置，普通用户不可见；
- 恢复前系统会创建 `pre-restore` 安全备份；
- 主密钥丢失会导致加密附件和备份无法恢复，主密钥必须离线保存。

## 对象存储与附件

- 对象存储是可选能力；不配置时附件继续保存在本机，行为不变。
- **启用备份副本**：每次工作区/整站备份都会上传一份已加密的 `.3nb`；实例概览显示每份整站备份的 S3 状态，失败可重试。
- **启用附件对象存储**：会先把本机已有附件上传到对象存储，再切换新上传。迁移按“同目录、同名称、同大小”检查，已存在则跳过上传；全部成功后才会把新附件写入对象存储。
- **停用附件对象存储**：会逐个从对象存储取回并校验，全部成功后才切回本机；可选择同时清理对象存储中的附件副本。失败时保持原状态，附件仍可读取。
- 附件链接始终是 `/api/attachments/:id/content`，存储后端切换不会改写笔记正文。
- 有附件在对象存储时，不能修改 endpoint/bucket/prefix/access key；必须先停用并取回，避免附件失联。
- 实例概览与数据设置分别显示：
  - 本机附件实际占用（含缩略图）；
  - 对象存储附件对象数与字节数；
  - 对象存储备份对象数与字节数。
- 整站备份会把仅存在于对象存储的附件也写入归档，避免恢复时缺附件。
- 迁移状态和进度在页面上实时显示；迁移中不要重启服务，重启不会损坏附件，但需要重新发起迁移。
- 迁移成功后会校验远端对象并清理本机副本；已有远端附件也可在存储管理点击“清理本机副本”，本机占用会相应下降。

## 判断站点是否正常

- `/health`：API 与数据库连通性、版本；
- 实例管理：活动会话、待处理/失败任务、最近备份；
- `journalctl -u 360note`：服务日志（不记录正文、密码或 Cookie）；
- `tests/manual/security-audit.mjs`：权限与安全回归；
- `tests/manual/responsive-audit.mjs`：多尺寸/主题前端回归。
