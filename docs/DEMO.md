# 360note 演示账户

演示账户用于检查排版、编辑器、组织、分享、权限与打印体验。

- 管理员：`access@126.com`
- 演示账户：`demo@360note.com`（普通用户角色）
- 密码、恢复密钥与演示分享链接：见服务器 `/root/360note-credentials.txt`（0600，不提交到仓库）
- 演示空间：`示例空间 / Demo`（个人）、`产品团队 / Product team`（团队，管理员为 admin 成员）

演示数据覆盖：

- 中英文笔记、Markdown 与富文本、GFM 表格、任务列表、引用、代码块、双向链接
- 图片附件、PDF、CSV 附件；附件面板与下载
- 文件夹、嵌套文件夹、多个标签、收藏、置顶
- 评论、通知、版本历史、公开分享（只读）与密码保护分享（可评论）
- 团队空间角色、成员、邀请入口、审计日志
- 移动端单屏布局与桌面三栏布局

## 快速检查

1. 使用演示账户登录 `https://360biji.com`，确认界面为中文；退出后登录 `https://360note.com`，确认界面为英文且内容一致。
2. 打开「欢迎来到 360笔记」，确认图片、表格、任务列表、附件与双向链接。
3. 在编辑器底部切换 Markdown/富文本，切到另一篇笔记再切回，确认模式按笔记独立记忆。
4. 打开右侧「信息 → 历史」，确认多次保存生成的版本。
5. 打开「产品团队」，确认成员角色、审计日志与团队笔记。
6. 使用公开分享链接与密码分享链接，确认只读/评论与密码边界。
7. 390px 移动端：确认无“拖入文件”等桌面文案，设置与空间切换可用。
8. 在「设置 → 账户」修改邮箱，确认需要新邮箱验证码与当前密码。
