# ADR-007: 加密空间（密码派生密钥）

- 状态：已实施（0.3.0）
- 日期：2026-11-15
- 关联：`docs/ARCHITECTURE.md`、`docs/FEATURES.md`、`docs/ADMIN.md`

## 背景

用户需要一种只能凭独立密码进入的空间：内容不可分享、不可双链、不可评论、不可导出，15 分钟无操作自动锁定，切换空间或刷新页面后必须重新输入密码。仅加一道密码门禁、正文仍明文落库，无法兑现“不可绕过”，因此采用密码派生密钥。

## 决策

1. **空间类型**：`workspaces.kind = 'vault'`，单所有者，不支持成员、邀请或所有权转移。
2. **密钥层级**：
   - 创建时生成随机 32 字节空间数据密钥。
   - 密码经 scrypt（N=32768, r=8, p=1）派生 KEK，AES-256-GCM 包裹数据密钥，保存 `vault_salt` / `vault_key_wrapped`。
   - 同时生成一次性恢复密钥（256 位随机），用 SHA-256 派生 KEK 包裹同一数据密钥；只保存恢复密钥哈希和包裹后的密钥。
   - 密码修改只重新包裹数据密钥，不重新加密内容。
3. **内存解锁**：解锁成功后数据密钥只保存在 Node 进程内存，按 `workspace + 解锁 token` 索引并绑定登录会话；15 分钟滑动过期。服务重启、退出登录、撤销会话、修改密码都会清除。
4. **每标签页 token**：解锁返回 `workspaceId.token`，客户端只保存在 JS 内存并通过 `X-360note-Vault` 请求头发送；刷新、关闭标签页或新标签页必须重新输入密码。服务端校验 token 哈希、会话绑定和过期时间。
5. **加密范围**：
   - 笔记标题、正文、摘要：`cipher_title` / `cipher_body`，明文列置空，FTS 搜索向量为空。
   - 版本历史：标题/正文以空间密钥加密后写入 `note_versions`。
   - 附件：字节以空间密钥加密；文件名加密；不生成缩略图、不 OCR、不做分享派生媒体。
   - 未加密：文件夹名、标签名、时间戳、大小、附件 MIME 等元数据；文档明确披露。
6. **禁用能力**：分享、公开链接、评论、双向链接/反向链接、单篇/整库导出、导入、AI/OCR、离线缓存/PWA 预取、工作区备份与恢复、API token 访问。服务端在路由层拒绝，UI 同时隐藏入口。
7. **锁定**：服务端 15 分钟滑动过期；客户端 15 分钟无操作主动锁定并清除 token/缓存；收到 423 时立即回到锁屏。锁屏提供“用恢复密钥恢复”和“忘记密码/恢复密钥时删除空间”两条明确出路。
8. **恢复**：恢复密钥使用后立即轮换；旧密码和旧恢复密钥失效。密码和恢复密钥都丢失时内容不可恢复，这是安全模型的必然代价。

## 为什么不叫端到端加密

解锁期间 Node 进程在内存中持有数据密钥并处理明文，因此不是“服务端永远看不到”的 E2EE。它实现的是**密码派生密钥的静态加密 + 服务端强制锁定**，密码不落库、不可由账号密码或实例管理员绕过。真正的 E2EE 需要客户端解密、客户端索引和附件密钥管理，见 ADR-006；本功能不声称提供 E2EE。

## 后果

- 加密空间内无法使用服务端全文搜索、评论、分享、导出、备份、AI/OCR 和离线编辑。
- 文件夹/标签名等元数据仍可见；如需隐藏，需要后续加密元数据并改为客户端树/标签索引。
- 忘记密码和恢复密钥时只能删除空间；不提供管理员后门。
- 单进程内存密钥模型；多进程部署需要共享的短期密钥服务或粘性会话。
